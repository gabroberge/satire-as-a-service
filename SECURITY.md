# Security Policy

## Supported versions

Satire-as-a-Service is currently under active development. Only the latest version is supported.

## Reporting a vulnerability

If you discover a security vulnerability, please report it privately using GitHub's security advisory feature rather than opening a public issue.

Please include enough information to reproduce and understand the issue.

## Scope

Satire-as-a-Service is a static satirical marketing site. It has no backend, authentication system, database, or user data. Nothing is stored, collected, or processed. Grievances submitted through the interface go nowhere, which is itself a form of data minimization.

Security issues affecting visitors, such as cross-site scripting, injection vulnerabilities, exposed secrets, or vulnerable dependencies, are in scope.

Fictional product behavior, fabricated metrics, the absence of the advertised platform, and the platform having generated its own landing page are not security vulnerabilities.

## Response

Valid reports will be reviewed as time permits. Reports are currently reviewed by a human. There is no bug bounty program.

## Safe harbor

Good-faith security research is welcome. Please avoid disruptive testing against the production deployment.
