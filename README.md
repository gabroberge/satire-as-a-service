## The platform

Seven managed stages from grievance to go-to-market. No step requires inspiration.

Included capabilities:

- **Grievance Ingestion™** — structured intake for anything that annoys you; sighs accepted (transcribed)
- **Brandification Engine™** — every dysfunction deserves a category leader
- **Enterprise Euphemism Layer™** — truth in, language out; meaning preserved end-to-end, no longer legible
- **Feature Synthesis™** — 14 trademarked capabilities per dysfunction, sustained
- **Credibility Calibration™** — satire performs best when someone could conceivably expense it
- **Recursive Satire™** — point the platform at its own output; recursion stable, original premise still detectable

This repository is deployment SAAS-0001. See the pipeline trace on the landing page.

## Getting started

```sh
bun install
bun dev
```

Production, to the extent a satirical landing page has production:

```sh
bun run build
bun run check
bun run preview
```

Built with Astro and Tailwind CSS. The site is fully static.
